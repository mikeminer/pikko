# Logo PIKKO

La "I" di PIKKO è il personaggio Pikko: germoglio (che fa anche da puntino della i), occhioni, guance, bavaglino a quadretti e oblò della pancia.

| File | Uso |
| --- | --- |
| `PIKKO_logo.svg` | Master vettoriale (scalabile, da usare ovunque possibile) |
| `PIKKO_logo_2000_transparent.png` | Sfondo trasparente, alta risoluzione |
| `PIKKO_logo_1000_transparent.png` | Sfondo trasparente, web/social |
| `PIKKO_logo_2000_cream.png` | Su sfondo crema del gioco (#f3e7d6) |
| `PIKKO_logo_2000_dark.png` | Su sfondo scuro (#2b1a10) |

Colori: arancio lettere `#ff6b35`, ombra 3D `#c94a1e`, contorno `#4a1d0c`, germoglio `#5bbf3a`.
Nel gioco: `pikko-game/public/pikko-logo.svg` (schermata di caricamento e titolo).
Per rigenerare i PNG: `node tools/render_brand_logo.mjs ../PIKKO_LOGO` dalla cartella `pikko-game`.
