# PIKKO for Android

A **Trusted Web Activity** (TWA) of https://pikko.art/play/: the phone's Chrome engine shows the game full screen, with no
browser bar. The app has no game code of its own, so it always runs the version the server serves.

It is deliberately **not a WebView**. Mobile Wallet Adapter (Seed Vault Wallet on the Solana Seeker, Solflare, Phantom) cannot start from a
WebView, so a WebView wrapper shows "connection cancelled" or "browser incompatible" when the player taps Connect wallet.
In a TWA the wallet connection works exactly as in Chrome. Without a Custom Tabs browser the app falls back to a Custom Tab, never a WebView.

- Package `art.pikko.app`, minSdk 24, target/compile SDK 36, `androidbrowserhelper` 2.7.3, AGP 8.13.0, Gradle 8.13.
- Opens `https://pikko.art/play/?source=app`; links to `https://pikko.art/play…` open in the app when it is installed.
- Android confirms the app/site pair through `https://pikko.art/.well-known/assetlinks.json` (generated by `build.mjs` from the release key; it must be deployed with the site).

## Build (Windows)

Requirements: JDK 17 and the Android SDK (`platforms;android-36`, `build-tools;36.0.0`) in `ANDROID_HOME` or `%LOCALAPPDATA%\Android\Sdk`.

```sh
node make-icons.mjs   # only if the game icon changes (needs `sharp`); the PNGs are committed
node build.mjs        # -> release/Pikko-<version>.apk, signed and verified
```

`build.mjs` creates the release key once (RSA-3072) in `%USERPROFILE%\PikkoArt\android-signing\`; its random password is kept only DPAPI-protected for this
Windows user. It writes the certificate fingerprint into `assetlinks.json`, runs Gradle `assembleRelease` + `lintRelease`, then `zipalign` and `apksigner sign` + `verify`.
Raise `versionCode` and `versionName` in `app/build.gradle.kts` for every update.

**Keep the key.** Every update in the Solana dApp Store must be signed with the same key. Back it up offline and keep the password in a password manager:

```sh
powershell -File backup-key.ps1 -Destination 'E:\AndroidKeys\pikko-release.p12'
```

Never put the key or its password in the repository, chat or email. APKs in `release/` are not committed.

## Install / test

Copy the APK to the phone, or `adb install -r release/Pikko-1.0.1.apk`. Check that Android verified the site:
`adb shell pm get-app-links art.pikko.app` should say `verified`. Not yet tested on a physical Seeker (built and signature-verified only).
